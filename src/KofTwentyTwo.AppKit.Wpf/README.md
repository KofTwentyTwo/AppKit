# KofTwentyTwo.AppKit.Wpf

WPF shell pieces for KofTwentyTwo Windows apps, mirroring the WinUI package.

- **`SplashOverlay.ShowOver(rootGrid, app, settings)`**: branded splash as an in-window overlay.
- **`AboutWindow.Show(app, owner)`**: identity, version, license, attributions.
- **`LogWindow.ShowSingle(log, app)`**: live, filterable activity-log viewer.
- **`MessageBoxPrompter`**: the update flow's dialogs.
- **`WpfShell`**: crash safety net, Windows 11 Fluent theme (`Application.ThemeMode`), and the app icon.

Source, samples, and docs: https://github.com/KofTwentyTwo/AppKit
